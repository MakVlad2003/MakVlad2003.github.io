# Владислав Макаров — личный сайт

Статический сайт на русском и английском: HTML, CSS и JavaScript. Сборка не нужна.

Локальный просмотр из этой папки:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/ или английскую версию http://127.0.0.1:8765/?lang=en.

- `content.js` — тексты на двух языках.
- `app.js`, `styles.css` — главная страница и интерактив.
- `viewer.html`, `viewer.js`, `viewer.css` — просмотр материалов по страницам, со встроенными видео.
- `assets/` — фотография, логотипы, оригинальные схемы методов, шрифты и их лицензии.
- `materials/` — страницы материалов, видео и файлы описания. Все эти файлы нужны сайту.
- `main_rus.pdf`, `main_eng.pdf` — CV для скачивания.
- `figure/` — оригиналы документов, сохранённые локально и исключённые из Git.
- `scripts/` — вспомогательные скрипты подготовки материалов.

Для повторной подготовки страниц из PDF и восстановления видео из PPTX: `python3 scripts/prepare-pages.py`. Нужны Pillow, Poppler и FFmpeg. Слайды ВКР и конференции берутся из исходных PDF, чтобы сохранить их вёрстку. Текст ВКР использует `figure/Макаров_Диплом_final.pdf`. Оригиналы не меняются.

Публикация и добавление ссылки в GitHub-профиль: [docs/PUBLISH.md](docs/PUBLISH.md).
